My Learning Experience

This page reflects on my experience learning web development, from starting with no HTML or CSS experience to building my own websites. It also highlights some of the skills I've gained and challenges I've encountered along the way.

Where I Started

Before taking this course, I had no experience with HTML or CSS. Although I had some previous experience learning Java, building websites was a completely new experience for me. I started this course with little knowledge of how websites were structured or styled, but I've enjoyed learning how the different pieces come together.

What I've Learned

Throughout this course, I've learned the basics of HTML and CSS and how they work together to create websites. I've practiced using HTML to organize content and CSS to style and arrange page elements. I've also learned about Flexbox, CSS Grid, and responsive design, which allow me to create layouts that work across different screen sizes.

Challenges Along the Way

One of the challenges I've faced while learning web development has been figuring out how to create different page layouts and designs. I sometimes find myself using similar layouts for different projects, and I'd like to get better at experimenting with different designs. Choosing colors and deciding how to arrange elements on a page can also be challenging. I've also found making websites responsive a little tricky, especially when trying to make sure everything looks right on different screen sizes.
